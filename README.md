# 💻 Portfolio - Akbar

Website portfolio pribadi yang dibuat sebagai media untuk memperkenalkan diri, menampilkan kemampuan, teknologi yang dipelajari, serta beberapa project yang pernah dikerjakan.

Website ini dibuat menggunakan HTML dan CSS tanpa menggunakan framework frontend.

---

## 🌐 Tentang Project

Website portfolio ini dirancang dengan tampilan modern, minimalis, dan responsif dengan tema dark mode.

Di dalam website terdapat beberapa section utama:

- 🏠 **Home** — Perkenalan singkat dan profil
- 👨‍💻 **About** — Informasi mengenai pendidikan, bidang, lokasi, dan fokus
- 🛠️ **Skills** — Teknologi dan tools yang sedang dipelajari
- 🚀 **Projects** — Beberapa project yang pernah dibuat
- 📩 **Contact** — Informasi untuk menghubungi saya

---

## ✨ Fitur

- Responsive design untuk desktop, tablet, dan mobile
- Dark mode dengan nuansa modern
- Smooth scrolling antar section
- Hover animation pada button dan project card
- Project showcase dengan screenshot aplikasi
- Skill showcase dengan icon teknologi
- Navigation bar dengan sticky position
- Social media links
- Contact section
- Layout yang menyesuaikan ukuran layar

---

## 🛠️ Teknologi yang Digunakan

### Frontend

- HTML5
- CSS3

### Library / Icon

- Font Awesome

### Design

- CSS Gradient
- CSS Flexbox
- CSS Grid
- CSS Animation & Transition
- Responsive Media Query
